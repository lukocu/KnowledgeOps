A customer running IBM Streams 4.1.1.2 as a system service reports that jobs do not pick up the ODBCINI variable from .bashrc and the database toolkit returns SQL error 08003. How do I fix it?
Odpowiedź

In Streams 4.1.1.1 and 4.1.1.2, jobs started while Streams runs as a system service may not inherit the user environment from .bashrc.

WSPIERA TEZĘ 3
Workaround: set the variables the application needs directly in the instance
IBM STREAMS 4.1.1.1 and 4.1.1.2 JOBS DO NOT INHERIT THE ENVIRONMENT VARIABLES SET IN .BASHRC, WHEN STREAMS IS RUN AS A SYSTEM SERVICE
swg21996508.txt · Problem Solution · data dokumentu: nieznana
… the database toolkit might show the following error if it does not pick up the ODBCINI environment variable: "An SQL operation failed. The SQL state is 08003…"
To work around the issue, set environment variables that are needed by the application directly in the instance with:
streamtool setproperty -d <domain> -i <instance> --application-ev <VARIABLE NAME>=<VARIABLE VALUE>
