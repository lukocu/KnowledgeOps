IBM Insufficient ulimit Value Causes Native OutOfMemory - United States
DIAGNOSING THE PROBLEM, akapit 6 · data: nieznana · wersja produktu: nie podano
WebSphere Application Server Support recommends setting the ulimit -u or nproc to a value of 131072 when running on Linux to safely account for all the forked threads within processes that could be created.
Kontekst powyżej
… For out of the box Red Hat Enterprise Linux (RHEL) 6 the default value for nproc will be set to 1024. This low default setting for larger systems will not allow for enough threads in all processes.
BSYN-KB-0007DOKUMENT SYNTETYCZNY
Runbook: WebSphere Application Server on Linux — process limits for application servers
Process limits, akapit 1 · data: 2019-03 (metadane syntetyczne) · wersja produktu: nie podano
Keep nproc at the RHEL default of 1024 for the WebSphere user. Do not raise the limit on application servers.

Applies to: WebSphere Application Server, Linux hosts managed by the platform team.
